## Sobre mí

🚀 Data Engineer con experiencia en diseño y optimización de pipelines de datos en Google Cloud Platform, trabajando con tecnologías modernas para la ingesta, transformación, modelamiento y procesamiento de datos.

💻 Trabajo principalmente con Python, SQL, BigQuery, dbt y dlt, integrando datos provenientes de múltiples fuentes como SAP HANA, SQL Server, PostgreSQL, APIs y Google Sheets.
☁️ Tengo experiencia trabajando con servicios de Google Cloud Platform, desarrollando procesos de datos orientados a la automatización, trazabilidad, integridad y control de costos.

🔄 Me interesa construir soluciones de datos confiables y mantenibles, desde la extracción y validación de información hasta su transformación y disponibilidad para análisis.

🧩 Mi experiencia previa en desarrollo de software con Python, Flask, APIs REST, Git y testing me permite aplicar buenas prácticas de ingeniería al desarrollo de soluciones de datos.
⚡ Soy una profesional adaptativa, constante y comprometida con el aprendizaje continuo. Disfruto resolver problemas, aprender nuevas tecnologías y colaborar en equipos donde pueda aportar y seguir creciendo.

🎯 Actualmente estoy enfocada en seguir desarrollándome profesionalmente en el área de Data Engineering, Data Platform y Analytics Engineering.
